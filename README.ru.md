# <img src="docs/logo.png" alt="" width="36" height="36" align="top"> BoxInside — профиль объёма каждой свечи для TradingView

**Видно, где стоял объём внутри каждой свечи.**
Перенос MetaTrader 4-индикатора *BoxInside* на TradingView: для каждой свечи строится собственный
профиль объёма по данным младшего таймфрейма. **POC** рисуется точкой, цвет которой зависит от объёма,
границы зоны стоимости **VAH / VAL** — ромбами.

## ✨ Возможности

|                                   |                                                                                       |
| --------------------------------- | ------------------------------------------------------------------------------------- |
| 🕯️ **Профиль каждой свечи**       | У каждой свечи свой профиль объёма, а не один на сессию или диапазон                  |
| 🎯 **POC · VAH · VAL**            | Точка контроля и обе границы зоны стоимости прямо на свече                            |
| 🎨 **6 градаций объёма**          | Цвет точки POC показывает, насколько велик объём на ней: от Lowest до Highest          |
| 📐 **Два метода градации**        | *Ratio to average* со своими порогами или *Percentile* — шесть равных групп            |
| 📏 **Два способа зоны стоимости** | *OfTotalVolume* (классический, может быть несимметричным) или *OfPocND* (±z·σ)         |
| 🧭 **Авто-выбор младшего ТФ**     | Берётся самый мелкий LTF, данных которого хватает на все *BarsLimit* свечей            |
| 🔀 **Dots / Curves**              | Метки на каждой свече или линии, соединяющие POC, VAH и VAL                           |
| 👁️ **Включение градаций**         | Любую градацию можно скрыть: например, оставить только **High** + **Highest**         |
| 📊 **Таблица-легенда**            | Шкала цветов, градация текущей свечи, используемый LTF и предупреждение о покрытии    |
| 🧮 **Режим TPO**                  | Нет объёма у инструмента — индикатор сам считает по времени в цене (Market Profile)    |
| 🔁 **История не перерисовывается**| Закрытые свечи сохраняют метки, обновляется только текущая                            |
| 🔝 **Поверх свечей**              | Метки рисуются над свечами, прозрачность настраивается                                |

## 🎯 Что показывает индикатор

| Метка                      | Значение                                                                          |
| -------------------------- | --------------------------------------------------------------------------------- |
| 🔵 **Цветная точка**       | **POC** (Point of Control) — цена с наибольшим объёмом внутри свечи                |
| ◆ **Серый ромб сверху**    | **VAH** (Value Area High) — верхняя граница зоны стоимости                         |
| ◆ **Серый ромб снизу**     | **VAL** (Value Area Low) — нижняя граница зоны стоимости                           |

Цвет POC — объём на POC относительно предыдущих свечей (по умолчанию *Ratio to average*):

| Цвет | Градация    | Объём POC относительно среднего |
| :--: | ----------- | :-----------------------------: |
|  🩵  | **Highest** |            ≥ 2.00×              |
|  🔵  | **High**    |          1.50 – 2.00×           |
|  🟢  | **Medium**  |          1.00 – 1.50×           |
|  🟡  | **Middle**  |          0.75 – 1.00×           |
|  🔴  | **Low**     |          0.50 – 0.75×           |
|  🟣  | **Lowest**  |            < 0.50×              |

> ⚠️ Как и в оригинале, положение и цвет меток на **текущей (незакрытой) свече** окончательны только
> ближе к её закрытию. На закрытых свечах индикатор не перерисовывается.

## ⚙️ Как это работает

```text
   Свеча графика (например, D1)                  Свечи младшего ТФ (например, H1)
 ┌─────────────────────────┐   request.security_lower_tf   ┌──────────────────────┐
 │ High ─────────────────  │ ◄──────────────────────────── │ high · low · volume  │
 │                         │                               │ каждой младшей свечи │
 │ Low  ─────────────────  │                               └──────────────────────┘
 └───────────┬─────────────┘
             ▼
   High–Low делится на N строк ──► объём младшей свечи поровну раскладывается по задетым строкам
             ▼
   POC = строка с наибольшим объёмом ──► зона набирается до ValueArea % ──► VAH / VAL
             ▼
   Объём POC против последних Lookback свечей ──► одна из 6 градаций ──► цвет точки
```

| Шаг | Что происходит                                                                                                  |
| :-: | --------------------------------------------------------------------------------------------------------------- |
|  1  | Для каждой из последних **BarsLimit** свечей скрипт получает high, low и volume всех младших свечей внутри неё   |
|  2  | Диапазон High–Low свечи делится на **Rows** ценовых строк (или строки фиксированной высоты **Ticks per row**)    |
|  3  | Каждая младшая свеча поровну раскладывает свой объём по строкам между своими low и high (в режиме TPO — по 1)    |
|  4  | **POC** — строка с наибольшим объёмом; при равенстве — ближайшая к центру свечи                                 |
|  5  | **Зона стоимости** — *OfTotalVolume*: растёт от POC в сторону соседней строки с бо́льшим объёмом, пока не наберёт *ValueArea %* объёма. *OfPocND*: VAH/VAL = POC ± z·σ, где σ — взвешенное по объёму отклонение цен от POC, а z соответствует *ValueArea %* (для 70 % z ≈ 1,04) |
|  6  | **Градация** — объём POC делится на средний объём POC за *Lookback* свечей (или берётся его процентиль)          |

Объём POC каждой свечи виден и в **окне данных** (Data Window) как *POC volume*.

## 🚀 Установка

1. Откройте [TradingView](https://www.tradingview.com/chart/) → внизу **Pine Editor**.
2. Создайте новый индикатор, удалите шаблонный код, вставьте содержимое
   [`BoxInside_v4.pine`](BoxInside_v4.pine).
3. **Save** → **Add to chart**.
4. Рабочие таймфреймы: **от M5 до MN** (как в MT4). На M1–M4 выберите *LTF = Вручную* и секундный
   таймфрейм, например `15S`.

> 💡 Индикатор работает и на бесплатном тарифе. Старшие тарифы только увеличивают лимит данных
> младшего ТФ (см. [глубину истории](#-младший-таймфрейм-и-глубина-истории)).

## 🎛️ Настройки

### 📈 Группа «Профиль»

| Параметр                          | По умолчанию        | Описание                                                                                     |
| --------------------------------- | ------------------- | -------------------------------------------------------------------------------------------- |
| **ValueArea, %**                  | 70                  | Размер зоны стоимости. Обычно 68–70 %. Чем больше, тем дальше VAH/VAL от POC                 |
| **ValueAreaType**                 | OfTotalVolume       | *OfTotalVolume* — классический способ, зона может быть несимметричной. *OfPocND* — симметрично ±z·σ относительно POC, с обрезкой по High/Low |
| **VolumesType**                   | Volume (Tick/Real)  | *Volume* — объём поставщика данных (тиковый на Forex/CFD, реальный на акциях, фьючерсах, крипте). *Without (TPO)* — каждая младшая свеча считается за 1 |
| **Rows (строк профиля)**          | 50                  | Ценовых строк на свечу (5–500). Больше строк — точнее POC, но медленнее. У маленьких свечей число строк ограничивается количеством тиков |
| **Ticks per row (0 = по Rows)**   | 0                   | Фиксированный шаг строки в тиках (аналог расчёта по пунктам в MT4). При > 0 параметр Rows игнорируется. Максимум 1000 строк на свечу |
| **LTF** + таймфрейм               | Auto по BarsLimit   | Младший таймфрейм для профиля — см. [режимы](#-младший-таймфрейм-и-глубина-истории)         |
| **BarsLimit**                     | 1000                | Для скольких последних свечей строить профиль (10–20 000)                                    |
| **Лимит младших баров тарифа**    | 100 000             | Сколько свечей младшего ТФ отдаёт TradingView: 100 000 (Basic…Premium), 125 000 (Expert), 200 000 (Ultimate) |

### 🖌️ Группа «Отображение»

| Параметр                              | По умолчанию | Описание                                                                   |
| ------------------------------------- | ------------ | -------------------------------------------------------------------------- |
| **DrawingMode**                       | Dots         | *Dots* — точка POC и ромбы VAH/VAL на каждой свече. *Curves* — линии, соединяющие уровни |
| **☑ VAHColor / ☑ VALColor**           | вкл, серый   | Галочка включает или выключает уровень, справа — его цвет                  |
| **Размер точки POC**                  | 4            | Толщина точки POC (1–10)                                                   |
| **Размер меток VAH/VAL (Dots)**       | Tiny         | Размер ромбов в режиме Dots: Tiny / Small / Normal / Large                 |
| **Толщина линий VAH/VAL (Curves)**    | 1            | Толщина линий VAH/VAL в режиме Curves (1–10)                               |
| **Цвет кривой POC (Curves)**          | фиолетовый   | Цвет линии POC в режиме Curves                                             |
| **Красить кривую POC по объёму**      | выкл         | В режиме Curves красить линию и точки POC цветами градаций                 |
| **Прозрачность меток, %**             | 0            | Метки рисуются поверх свечей. При 30–50 % свечи видны сквозь метки         |

### 🎨 Группа «Цвета POC по объёму»

Шесть цветов от наименьшего объёма на POC к наибольшему (имена как в MT4). **Галочка слева от
цвета** включает или выключает свечи этой градации.

| Параметр               | По умолчанию     | Градация                        |
| ---------------------- | ---------------- | ------------------------------- |
| ☑ **LowestBoxColor**   | вкл, фиолетовый  | минимальный объём               |
| ☑ **LowBoxColor**      | вкл, красный     | низкий                          |
| ☑ **MiddleBoxColor**   | вкл, золотой     | ниже среднего / около среднего  |
| ☑ **MediumBoxColor**   | вкл, зелёный     | около среднего / выше           |
| ☑ **HighBoxColor**     | вкл, синий       | высокий                         |
| ☑ **HighestBoxColor**  | вкл, голубой     | максимальный                    |
| **Скрывать и VAH/VAL у выключенных градаций** | вкл | Вкл — у свечи выключенной градации скрываются все метки (POC, VAH, VAL). Выкл — только точка POC |

> Выключение градации влияет только на отображение: средний объём и градации по-прежнему считаются по
> всем свечам, поэтому цвета оставшихся меток не меняются. В режиме Curves на месте скрытых свечей
> линии прерываются.

### 📐 Группа «Градация объёма POC»

| Параметр       | По умолчанию                     | Описание                                                                                     |
| -------------- | -------------------------------- | -------------------------------------------------------------------------------------------- |
| **Метод**      | Ratio to average                 | *Ratio to average* — объём POC делится на средний объём POC за *Lookback* свечей и сравнивается с порогами. *Percentile* — процентильный ранг среди последних *Lookback* свечей, шесть групп примерно по 16,7 % |
| **Lookback**   | 100                              | Сколько предыдущих свечей участвует в сравнении (5–2000)                                     |
| **Пороги**     | 0.50 / 0.75 / 1.00 / 1.50 / 2.00 | Только для *Ratio to average*, в долях среднего. **Должны идти по возрастанию**             |

### 📊 Группа «Таблица»

| Параметр                | По умолчанию | Варианты                                          |
| ----------------------- | ------------ | ------------------------------------------------- |
| **Показывать таблицу**  | вкл          | Показать / скрыть таблицу-легенду                 |
| **Позиция**             | Top Right    | Top Right · Top Left · Bottom Right · Bottom Left |
| **Размер текста**       | Small        | Tiny · Small · Normal                             |

## 🧭 Младший таймфрейм и глубина истории

**Режимы LTF:**

| Режим                                  | Как выбирается младший ТФ                                                                          |
| -------------------------------------- | -------------------------------------------------------------------------------------------------- |
| **Auto по BarsLimit** *(по умолчанию)* | Самый мелкий из M1, M2, M3, M5, M10, M15, M30, H1, H2, H4, D1, данных которого хватает на все *BarsLimit* свечей. При небольшом BarsLimit — как в MT4 (M1 для H1), при большом укрупняется (H1 + BarsLimit 5000 → M5) |
| **Auto как MT4**                       | Фиксированная таблица ниже                                                                         |
| **Вручную**                            | Таймфрейм, выбранный справа                                                                        |

| Таймфрейм графика | Auto как MT4 |
| ----------------- | :----------: |
| M5 … H1           |      M1      |
| H2 … H4           |      M5      |
| до D1             |     M30      |
| W1                |      H4      |
| MN                |      D1      |

**Почему глубина ограничена.** Профиль строится из младших свечей внутри каждой свечи графика, а
TradingView отдаёт скрипту **не больше 100 000 младших свечей** (Expert — 125 000, Ultimate — 200 000).
Сколько свечей графика они покрывают, зависит от соотношения ТФ:

| График + LTF | Младших на 1 свечу | Хватит на свечей графика (100 000) |
| ------------ | :----------------: | :--------------------------------: |
| M15 + M1     |         15         |              ≈ 6 600               |
| H1 + M1      |         60         |            **≈ 1 660**             |
| H4 + M5      |         48         |              ≈ 2 080               |
| D1 + M30     |         48         |            **≈ 2 080**             |
| H1 + M5      |         12         |              ≈ 8 300               |

Режим *Auto по BarsLimit* сам укрупняет LTF, чтобы данных хватило на все запрошенные свечи
(H1 + BarsLimit 5000 → M5, D1 + BarsLimit 3000 → H1). Последняя строка таблицы показывает покрытие и
становится **оранжевой**, если данных не хватило: `⚠ профиль: N из M свечей — выберите LTF крупнее`.

> Сам график TradingView загружает от 5 000 до 40 000 свечей в зависимости от тарифа. Свечей сверх
> этого BarsLimit не покажет.

## 📊 Таблица-легенда

Таблица (по умолчанию справа вверху) показывает текущее состояние индикатора:

- 🎨 шесть строк градаций с цветом, названием и диапазоном; градация **текущей свечи** подсвечена и
  отмечена `◄`;
- ◆ строки **VAH** и **VAL** с их цветами и размером зоны ValueArea %;
- ✕ выключенные галочками градации и уровни показаны бледными, со значком **✕** и надписью `выкл`;
- 📈 **Текущая** — объём на POC последней свечи и его отношение к среднему (или процентиль);
- 🧭 используемый LTF, ValueArea % и способ расчёта зоны;
- ✅ покрытие — сколько свечей получили профиль (оранжевое, если меньше BarsLimit).

> TradingView не позволяет кликать по таблице индикатора, поэтому градации включаются галочками в
> настройках, а таблица показывает их состояние.

## 💡 Рекомендуемые настройки

| Задача                                           | Настройки                                                         |
| ------------------------------------------------ | ----------------------------------------------------------------- |
| 🖥️ Как в MT4 (дневка, Forex)                     | D1, LTF = Auto как MT4 (M30), ValueArea 70, OfTotalVolume, Dots    |
| ⏱️ Внутридневная торговля                        | M15–H1, LTF = Auto по BarsLimit, Rows 30–50, BarsLimit 500–1500    |
| 📜 Длинная история на H1 / D1                    | BarsLimit 5000+, LTF = Auto по BarsLimit (укрупнит LTF сам)        |
| 〰️ Смещение POC / зоны стоимости во времени       | DrawingMode = Curves                                              |
| ⚖️ Равномерная раскраска независимо от волатильности | Метод = Percentile, Lookback 100–200                          |
| 🔥 Только свечи с крупным объёмом                | Оставьте ☑ High и ☑ Highest, остальные четыре градации снимите    |
| 🚫 У инструмента нет объёма                      | VolumesType = Without (TPO)                                       |

## 🔄 Отличия от MT4-версии

- 🔒 Исходный `box-inside-bar.ex4` скомпилирован и зашифрован (MT4 build 600+), поэтому алгоритм
  восстановлен по описанию и скриншотам автора, а не по исходному коду. Значения по умолчанию и правило
  выбора цвета POC в оригинале не опубликованы: здесь они настраиваются, а цвета по умолчанию взяты со
  скриншотов.
- 📦 Вместо отдельных режимов *Tick* и *Real* используется единый объём TradingView (тиковый на
  Forex/CFD, реальный на остальных рынках).
- ➕ Добавлены: *Rows* / *Ticks per row*, ручной выбор LTF, метод и пороги градации, включение градаций,
  таблица-легенда.
- 📉 Глубина истории ограничена лимитом TradingView на данные младшего ТФ ([подробнее](#-младший-таймфрейм-и-глубина-истории)).

| 🕯️ Текущая свеча           | Метки на незакрытой свече смещаются до её закрытия — решения принимайте по закрытым свечам      |
| 📉 Глубина истории         | Ограничена 100 000 / 125 000 / 200 000 младших свечей по тарифу; крупный LTF глубже, но грубее  |
| 📊 Объём на Forex          | Тиковый объём у разных фидов (OANDA, FXCM, брокеры) разный — градации на разных символах EUR/USD немного отличаются |
| ⏱️ Графики M1–M4           | Нужен секундный LTF, выбранный вручную; автоматические режимы начинаются с M1                   |
| 🖱️ Нет событий мыши        | В Pine Script нет событий мыши, поэтому таблица только показывает состояние, а слой меток не меняется при наведении |
